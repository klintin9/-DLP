# 🛡 DLP-Prototype: Модель предотвращения утечек данных

**Курсовая работа** по направлению 10.03.01 «Информационная безопасность» (профиль: Безопасность автоматизированных систем в финансово-банковской сфере).
**Автор:** Идусуи Клинтин Вестлей (Группа ИБ23-5, Финансовый университет при Правительстве РФ).

## 📌 Описание проекта

В условиях цифровой трансформации утечки конфиденциальных данных через коммуникационные каналы (электронная почта, мессенджеры, файлы) являются одной из ключевых угроз. Более 60% таких инцидентов происходят из-за человеческого фактора. 

Данный репозиторий содержит **прототип системы DLP (Data Loss Prevention)**, разработанный на языке Python. Скрипт предназначен для автоматизированного поиска конфиденциальной информации в текстовых файлах и демонстрации базовых алгоритмов предотвращения утечек.

## 🚀 Функционал

На данный момент прототип реализует базовый сигнатурный анализ (RegEx) для поиска следующих типов данных:
*   **Номера банковских карт** (13–16 цифр с пробелами или дефисами);
*   **Email-адреса**;
*   **API-ключи и токены** (паттерны вида `api_key = sk_live_...`).

**Особенности работы:**
*   Автоматическое сканирование файла `test.txt` в папке `data/`.
*   Вывод найденных совпадений с указанием номера строки.
*   Логирование всех инцидентов в файл `dlp.log`.

## 🛠 Технологии

*   **Python 3.x**
*   Стандартные библиотеки: `re` (регулярные выражения), `pathlib` (работа с путями), `os` (работа с файловой системой).
